## ⚡ Ключевая информация

### Сколько стоит событие?
- **Глава 1** — полностью **бесплатно** (0 кристаллов энергии)
- **Главы 1-4** — можно пройти бесплатно/с минимальными тратами (~320 кристаллов)
- **Главы 1-6** — требуется ~790 кристаллов энергии (примерно $40-50)
- **Главы 7-9** (Архидемон) — для платных игроков с высокими баффами

### Главные ресурсы
- **🔋 Кристаллы энергии** — для улучшения реликвий и открытия глав
- **💰 Монеты отваги** — для спинов на Алтаре Судьбы (главный источник осколков Евы)
- **💎 Сапфировые медальоны** — для покупок в магазине события
- **🌀 Печати Бездны** — для доступа к главам Архидемона (7-9)

### Главное правило
**Сначала улучшайте Том Жадности (Tome of Greed)** — он даёт бонусные монеты отваги при трате кристаллов энергии. Это самая важная реликвия!

## 🏆 Что можно получить

- **Ева** — новый герой (до 6 звёзд = 630 осколков душ)
- **Фрагменты артефактов Евы** — 18,400 штук для максимальной прокачки
- **Тотем на выбор** — за прохождение высоких глав (с оплатой)
- **Ресурсы прокачки** — камни кожи героев, катализаторы, золото

## ⚠️ Важные предупреждения

1. ⏰ **Событие идёт 7 дней** — не откладывайте на последний день!
2. 💸 **Не тратьте монеты отваги сразу** — сначала прокачайте Грааль Щедрости для скидки
3. 🔄 **Монеты лавки восстанавливаются** при перезапуске главы — не бойтесь экспериментировать
4. 🏪 **Магазин исчезает** после окончания события — потратьте все медальоны!
5. 📊 **Планируйте заранее** — используйте оптимизатор на hwdaily.win/eva-event/optimizer
