# 📋 Квесты и задания события

## Типы квестов

В событии "Freedom Protocol" есть несколько категорий квестов, которые дают **Кристаллы энергии**, **Монеты отваги** и другие награды.

---

## 🎯 Основные квесты (Main Tasks)

### 1. Битвы события (Event Battles)

| Задание | Награда (Монеты отваги) |
|---------|------------------------|
| Выиграть 1 бой | 3,000 |
| Выиграть 2 боя | 3,000 |
| Выиграть 3 боя | 3,000 |
| Выиграть 5 боёв | 3,000 |
| Выиграть 8 боёв | 3,000 |
| Выиграть 16 боёв | 3,000 |
| Выиграть 32 боя | 3,000 |
| Выиграть 64 боя | 3,000 |

**Итого:** 24,000 монет отваги

**Совет:** Глава I — бесплатная, поэтому после прохождения можно фармить её снова и снова для выполнения квеста на 64 боя.

---

### 2. Эволюция Евы (Eva Evolution)

| Задание | Награда (Монеты отваги) |
|---------|------------------------|
| Достичь уровня эволюции 2 для Евы | 250 |
| Достичь уровня эволюции 3 для Евы | 500 |
| Достичь уровня эволюции 4 для Евы | 750 |

**Итого:** 1,500 монет отваги

**Как выполнить:** Получайте камни душ Евы через Алтарь Судьбы и улучшайте её звёзды.

---

### 3. Искусство Боя (Art of Combat)

| Задание | Награда (Монеты отваги) |
|---------|------------------------|
| Достичь суммарного уровня способностей 50 для Евы | 100 |
| Достичь суммарного уровня способностей 100 для Евы | 150 |
| Достичь суммарного уровня способностей 150 для Евы | 200 |
| Достичь суммарного уровня способностей 200 для Евы | 300 |
| Достичь суммарного уровня способностей 250 для Евы | 400 |
| Достичь суммарного уровня способностей 300 для Евы | 500 |
| Достичь суммарного уровня способностей 350 для Евы | 600 |
| Достичь суммарного уровня способностей 400 для Евы | 750 |

**Итого:** 3,000 монет отваги

**Как выполнить:** Прокачивайте способности Евы (4 основных навыка). Суммарный уровень = сумма уровней всех четырёх способностей.

---

### 4. Вызов Архидемона (The Archdemon's Challenge)

| Задание | Награда |
|---------|---------|
| Нанести хотя бы 100,000,000 урона в бою с Архидемоном | Кристаллы энергии |
| Нанести хотя бы 200,000,000 урона в бою с Архидемоном | Кристаллы энергии |
| Нанести хотя бы 300,000,000 урона в бою с Архидемоном | Кристаллы энергии |

**Как выполнить:** Требует доступа к главам Архидемона (VII-IX), которые открываются Печатями Бездны.

## 🏅 Боевой пропуск (Battle Pass / Eva's Path)

Боевой пропуск состоит из **бесплатного** и **платного** треков наград.

### Бесплатный трек (Free Rewards)

Содержит:
- Кристаллы энергии
- Монеты отваги
- Сапфировые медальоны
- Базовые ресурсы прокачки

### Платный трек (Paid Rewards)

**Стоимость:** ~$10-15

Содержит:
- 10 камней душ Евы
- 150+ дополнительных кристаллов энергии
- 5,000+ монет отваги
- 40 сапфировых медальонов
- Камни кожи героев (15-40 штук)
- Катализаторы (320 штук)
- Изумруды (750 штук)
- Золото (10M+)
- Фрагменты артефактов (1,600 штук)

**Стоит ли покупать?**
Если вы планируете дойти до Главы IV и выше — платный пропуск значительно ускоряет прогресс и даёт хорошее соотношение цена/ценность.

## 💡 Советы по выполнению квестов

### Приоритет квестов:
1. **Битвы события** — самый простой способ получить монеты
2. **Эволюция Евы** — выполняется автоматически при прокачке героя
3. **Искусство Боя** — требует ресурсов, выполняйте после получения Евы
4. **Архидемон** — только для платных игроков, последний приоритет

### Как фармить квест на 64 боя:
После прохождения Главы I вы можете:
- Перезапустить главу
- Пройти 8 боёв снова (7 обычных + 1 босс)
- Повторить 8 раз для получения 64 побед
- Это даёт 24,000 монет отваги бесплатно!

### Оптимизация времени:
- Включайте **автобой** (кнопка ⟳) для ускорения
- Используйте **x2 скорость** (если доступна)
- Фармите Главу I в последние дни события для добивания квестов

## ⏰ График выполнения

### День 1-2:
- Пройти Главу I
- Начать выполнение квестов на победы
- Прокачать Тома Жадности

### День 3-4:
- Активные бои для квестов
- Достичь 16-32 побед
- Пройти Главы II-III

### День 5-6:
- Добить квест на 64 победы фармом Главы I
- Прокачать способности Евы (квесты Art of Combat)
- Пройти Главы IV-V

### День 7:
- Финальная проверка всех квестов
- Забрать все незаконченные награды
