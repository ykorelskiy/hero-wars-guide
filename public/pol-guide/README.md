что и гайды по Валдуру, Алекто и титанам. Одна HTML-страница, тёмная тема,

## Калькулятор

`assets/js/main.js` реализует функцию `initCalc()`:

- Чекбоксы и дропдауны для каждого источника кристаллов
- Корректная обработка Золотого билета (заменяет Battle Pass + VIP)
- Таблица медальонов применяется точно по накопительным порогам
- Показывает итоговый бюджет, максимальную главу и сколько не хватает до следующей
- Подсказка, что добавить, если бюджета чуть не хватает

Отладка из консоли: `window.PolCalc.CHAPTERS`.

## Ключевые данные события

### Порядок реликвий (правило без исключений)

```
Том жадности → Грааль щедрости → Амулет битвы
```

Амулет качается только до уровня, нужного для открытия следующей главы.

### Стоимость глав (нарастающим итогом)

| Глава | Кристаллов |
|---|---|
| 1–2 | 0 |
| 3 | 50 |
| 4 | 160 |
| 5 | 320 |
| 6 | 530 |
| 7 | 790 |

### F2P бюджет

| Источник | Кристаллов |
|---|---|
| Квесты + витрина (бесплатно) | 438 |
| + Battle Pass | +40 |
| + 3 подарка разработчиков | +48 |
| + 30 медальонов | +30 |
| **Итого ориентир** | **≈ 556** |

556 кристаллов → уверенная 6-я глава (нужно 530).
